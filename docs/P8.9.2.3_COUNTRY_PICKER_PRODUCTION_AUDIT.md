# P8.9.2.3 — Country Picker Production Hardening Audit

## Changes

### Phase B — SVG Flags
- New `src/components/ui/FlagIcon.tsx` — wraps `country-flag-icons/react/3x2`
- ISO badge fallback when flag not available
- Replaced `getFlagEmoji()` calls in trigger button and list rows
- Consistent rendering on Android, iOS, Windows, macOS — no emoji rendering

### Phase C/D/E — VisualViewport Keyboard Safety
- `useVisualViewport()` hook — listens to `visualViewport.resize/scroll`
- Computes keyboard height as `window.innerHeight - visualViewport.height - offsetTop`
- `keyboardHeight` applied as `style={{ bottom: keyboardHeight }}` on bottom sheet
- Sheet floats above keyboard on mobile — search stays visible, list scrollable
- No-op on desktop (keyboard height stays 0)

## Remaining known limitations (out of scope)
- No virtualized list rendering
- No localized country names
- No drag-to-dismiss bottom sheet
