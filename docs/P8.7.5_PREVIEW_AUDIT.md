# P8.7.5 Preview Audit — Context-aware URL Coverage

## Overview

This document audits every Preview button in the admin interface after the P8.7.5 context architecture upgrade. All preview buttons now use `PreviewButton` which reads `useTenantStore` and `useBranchStore.adminActiveBranch` to generate context-aware public URLs via `hrefToPublicUrl()`.

---

## URL Builder Logic

```typescript
// src/utils/public-url.ts
hrefToPublicUrl(href, tenantSlug, branchSlug)
// Example: hrefToPublicUrl('/menu', 'savor', 'main')
// → '/savor/main/menu'

// Fallback when context unavailable:
// hrefToPublicUrl('/menu', null, null) → '/menu'
```

## Context Initialization Flow

```
Admin clicks "Preview Menu"
    ↓
PreviewButton reads useTenantStore → tenant.slug = 'savor'
PreviewButton reads useBranchStore → adminActiveBranch.slug = 'main'
PreviewButton calls hrefToPublicUrl('/menu', 'savor', 'main')
    ↓
Returns '/savor/main/menu'
    ↓
New tab opens at /savor/main/menu
    ↓
[tenantSlug]/[branchSlug]/layout.tsx runs
  → useEffect: loadTenant('savor') if needed
  → useEffect: setAdminActiveBranch(branch with slug 'main')
    ↓
[tenantSlug]/[branchSlug]/menu/page.tsx renders MenuContent
MenuContent reads from useTenantStore + useBranchStore
    ↓
Customer sees correct menu for savor/main ✓
```

---

## Fallback Behavior

When `adminActiveBranch` is `null` (no branch selected yet):

- `PreviewButton` generates flat fallback URL: `/menu` instead of `/savor/main/menu`
- This preserves backward compatibility
- The `AdminBranchSwitcher` auto-selects the first branch when branches load, so null state is transient
