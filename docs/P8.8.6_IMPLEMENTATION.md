# P8.8.6 — Business Website Builder & Public Content Management: Implementation

## Overview

Turns every tenant homepage into a fully customizable business website managed from the Admin Panel. Owners can enable/disable sections, customize hero content, edit About and Contact info, set theme colors, preview live, manage branch-specific overrides, and restore previous versions — all without touching code.

## Phase C — Service Layer

**New file:** `src/services/website-builder.service.ts`

- Mock: reads/writes to `tenant.settings.websiteBuilder` via `tenantService.updateTenantSettings`
- `extractLayout(settings)` — safely merges stored layout with defaults
- Methods:
  - `getLayout(tenantSlug)` → `HomepageLayout`
  - `saveLayout(tenantSlug, layout)` → `HomepageLayout` (sets `lastSavedAt`)
  - `publishLayout(tenantSlug, layout)` → `HomepageLayout` (status → 'published', creates version)
  - `restoreVersion(tenantSlug, versionId)` → `HomepageLayout` (status → 'draft')
  - `getBranchOverrides(tenantSlug, branchSlug)` → `BranchContentOverrides`
  - `saveBranchOverrides(tenantSlug, branchSlug, overrides)` → `BranchContentOverrides`

**Updated:** `src/services/endpoints.ts` — added `WEBSITE_BUILDER` section:
```
LAYOUT:          GET/PUT /tenants/{slug}/website/layout/
PUBLISH:         POST    /tenants/{slug}/website/publish/
RESTORE:         POST    /tenants/{slug}/website/versions/{versionId}/restore/
VERSIONS:        GET     /tenants/{slug}/website/versions/
BRANCH_OVERRIDES: GET/PUT /tenants/{slug}/branches/{branchSlug}/website/overrides/
MEDIA_UPLOAD:    POST    /tenants/{slug}/website/media/
```

## Phase E — Admin UI

**New file:** `src/app/console/website/page.tsx`

Tabbed admin interface with 8 tabs:

| Tab | Content |
|-----|---------|
| Sections | Enable/disable/reorder homepage sections with toggle switches and up/down arrows |
| Hero | Headline, subheadline, background image, CTA button, alignment, theme, overlay opacity, mobile variant |
| About | Story, mission, history, founder name/bio/image |
| Contact | Phone, email, website, WhatsApp, Instagram, Facebook, TikTok, YouTube, Telegram, map embed, coordinates |
| Theme | Primary/accent/background colors, border radius, card style, font family, dark mode preference |
| Preview | In-page preview mockup + link to live public page |
| Branches | Per-branch content overrides (hero, phone, description, about) |
| Versions | Version history + one-click restore to any previous publish |

Action buttons:
- **Save** (disabled when no unsaved changes) — persists draft without publishing
- **Publish** — creates a version snapshot, sets status to 'published'

Status chip shows 'Draft' or 'Published'. Unsaved-changes banner shown when draft differs from saved.
