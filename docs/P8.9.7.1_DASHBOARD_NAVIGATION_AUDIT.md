# P8.9.7.1 — Dashboard Navigation Audit

## Summary

The platform has two distinct application areas. The routes and layouts are
already separate, but one labelling error inside the Admin Console sidebar
caused `/console` to be presented under the name "Dashboard", creating
conceptual confusion between the two areas.

---

## Application Areas

### Business Console — `/console`
Used by: owners, admins, managers, staff, cashiers, kitchen, marketing, support.

**Auth guard:** `AuthGuard requiredPermission="dashboard:access"` in `src/app/console/layout.tsx`.

**Layout components:**
- `AdminHeader` — replaces consumer Header inside /console
- `AdminSidebar` — grouped RBAC-filtered navigation
- `AdminContextBar` — tenant + branch switchers
- `AdminBreadcrumbs` — breadcrumb rooted at /console

**Routes (48 pages):**
/console → role-aware redirect (renders null, immediately replaces)
/console/analytics, /console/audit-logs/*, /console/bar/*
/console/branches/*, /console/cafe/*, /console/customers/*
/console/food-court/*, /console/food-truck/*
/console/kitchen, /console/loyalty, /console/menu
/console/mobile-cafe/*, /console/notifications/*
/console/operations, /console/orders/*, /console/permissions/*
/console/promotions/*, /console/reservations/*
/console/reviews, /console/roles/*, /console/settings/*
/console/staff/*, /console/tenants/*, /console/users/*
/console/vendors/*, /console/website

### Customer Dashboard — `/dashboard`
Used by: any authenticated user (all roles, including owners seeing their own customer profile).

**Auth:** `useAuthStore` + `useEffect` redirect in `src/app/dashboard/layout.tsx`.

**Layout components:**
- Consumer `Header` (same as public pages)
- Inline sidebar with `getDashboardNav()` items

**Routes (6 pages):**
/dashboard          — Overview (stats, recent orders, upcoming reservations)
/dashboard/orders   — My Orders
/dashboard/favorites — Favorites
/dashboard/addresses — Addresses
/dashboard/reservations — My Reservations
/dashboard/settings — Profile / Account settings

## Mislabeling Audit

### Finding: "Dashboard" in AdminSidebar points to `/console`

| File | Line | Label | href | Correct? |
|---|---|---|---|---|
| `src/components/admin/AdminSidebar.tsx` | 263 | "Dashboard" | `/console` | ❌ Misleading |

**Problem:** The always-visible first nav item in the Admin Sidebar is labelled
"Dashboard" and points to `/console`. A user reading this label cannot tell
whether it means the Business Console home or the Customer Dashboard.

**Fix:** Rename to "Console Home" (clearly signals admin area). Add a separate
"Customer Dashboard" item pointing to `/dashboard`.

---

### Finding: `aria-label` in AdminHeader says "go to dashboard"

| File | Line | aria-label | href | Correct? |
|---|---|---|---|---|
| `src/components/admin/AdminHeader.tsx` | 52 | `"...go to dashboard"` | `/console` | ❌ Ambiguous |

**Fix:** Change to `"...go to admin console"`.
