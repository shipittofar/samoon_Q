# P8.8.11.4 — Smart Customer Journey Engine: Implementation

## Summary

Introduces a business-type-aware `buildCustomerJourney()` engine that wraps the Public Context Engine (P8.8.11.3) to add priority ordering of CTAs, homepage sections, and navigation links — without duplicating any resolution logic.

---

## Architecture

```
Tenant.businessTypes[0]  +  buildPublicCTAs() output
            │
            ▼
    buildCustomerJourney()          ← NEW: src/utils/journey.ts
            │
   ┌────────┼──────────────┐
   │        │              │
sectionOrder  primaryCTA   navPriority
   │        + secondaryCTAs      │
   │                       │
   ▼                       ▼
TenantHomepageClient   buildTenantNavigation()
BranchHomepageClient     (journeyNavPriority hint)
```

**Key design decisions:**
- Journey engine takes `ctas: PublicCTASet` as input — never re-resolves feature flags.
- Website Builder `layoutNavConfig` ordering still overrides `journeyNavPriority` entirely.
- `buildPublicSections()` still controls section *visibility*; journey controls *order*.
- `getSmartCTA()` continues to drive hero CTAs; journey drives QuickActions.

## New Files

### `src/utils/journey.ts`

Single source of truth for business-type journey profiles.

**Exports:**
- `buildCustomerJourney(opts)` — main builder
- `PrimaryBusinessType` — union type
- `CustomerJourney` — output interface
- `BuildCustomerJourneyOptions` — input interface

**Output shape:**
```typescript
interface CustomerJourney {
  sectionOrder: SectionKey[]        // body section render order (excl. hero)
  primaryCTA: PublicCTALink | null  // highest-priority CTA for this business
  secondaryCTAs: PublicCTALink[]    // remaining active CTAs in priority order
  navPriority: string[]             // nav key order hint
}
```

### `src/test/journey.test.ts`

29 tests covering:
- Section order for all 8 business types
- CTA priority for all business types and flag combinations
- Nav priority for all business types
- Integration with `buildPublicCTAs()`

## Modified Files

### `src/utils/navigation.ts`

Added `journeyNavPriority?: string[]` to `BuildTenantNavOptions`.

New Step 4 (between multi-branch injection and Website Builder config):
```typescript
// Only applied when Website Builder has no ordering config
if (!hasWBOrdering && journeyNavPriority?.length) {
  // reorder businessItems by journeyNavPriority
}
```

Website Builder config (Step 5) still takes full precedence.

### `src/utils/index.ts`

Added exports for `buildCustomerJourney`, `PrimaryBusinessType`, `CustomerJourney`, `BuildCustomerJourneyOptions`.

### `src/components/layout/TenantHeader.tsx`

Computes `journey.navPriority` and passes it to `buildTenantNavigation()` as `journeyNavPriority`. Uses `buildPublicCTAs()` (already resolving featureFlags via store) to get the CTA set for the journey engine.

### `src/app/[tenantSlug]/TenantHomepageClient.tsx`

- `QuickActions` now accepts `journey: CustomerJourney` instead of computing CTAs internally.
- Renders `[journey.primaryCTA, ...journey.secondaryCTAs]` in order; first CTA gets accent style (primary conversion path).
- Main component builds `ctas` + `journey` once after hooks resolve.
- Section render loop: `journey.sectionOrder.map(key => sectionNodes[key])`.
- `CategoriesSection` (structural nav) is bundled inside the `featured_menu` slot so it always renders adjacent to menu content regardless of where `featured_menu` lands in the journey order.

### `src/app/[tenantSlug]/[branchSlug]/BranchHomepageClient.tsx`

Same pattern as TenantHomepageClient:
- `QuickActions` accepts `journey` prop; renders journey-ordered feature CTAs + fixed branch CTAs (Call, Directions, Share).
- Branch-specific CTAs (phone, directions, share) are intentionally outside the journey order — they depend on branch data, not feature flags.
- Section render uses an IIFE with `sectionNodes` map; `branches` key filtered out of main column (always in sidebar via `BranchSwitcher`).

### Section Order Profiles

| Type | Order |
|------|-------|
| restaurant | featured_menu → reviews → about → gallery → branches → promotions |
| cafe | featured_menu → promotions → about → reviews → gallery → branches |

| food_truck | branches → featured_menu → promotions → about → reviews → gallery |
| mobile_cafe | branches → featured_menu → promotions → about → reviews → gallery |
| food_court | branches → featured_menu → about → reviews → gallery → promotions |
| hotel | about → featured_menu → reviews → gallery → promotions → branches |
| other | featured_menu → about → reviews → gallery → branches → promotions |

### CTA Priority Groups

| Group | Business Types | Priority Order |
|-------|---------------|----------------|
| reservation-first | restaurant, bar, hotel | reservation → menu → loyalty → locations |
| location-first | food_truck, mobile_cafe | locations → menu → reservation → loyalty |
| menu-first | cafe, food_court, other | menu → loyalty → reservation → locations |
