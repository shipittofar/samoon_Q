Transforms reviews from hardcoded mock content into a complete, data-driven trust ecosystem. Business and branch pages now display real review data, rich review cards, rating breakdowns, owner replies, and AggregateRating structured data for SEO.

## Phase B — Review Model

**New file:** `src/types/business-review.ts`

```typescript
type ReviewStatus = 'published' | 'pending' | 'hidden' | 'spam' | 'deleted' | 'rejected'

interface OwnerReply { id, text, authorName, createdAt, updatedAt? }

interface BusinessReview {
  id, tenantId, branchId?, customerId?, customerName, avatar?
  rating, title?, comment, images?, visitDate?, visitType?
  createdAt, updatedAt, ownerReply?, helpfulCount, verifiedVisit
  status: ReviewStatus, language?, pinned?
}

interface RatingBreakdownData { average, total, distribution: RatingDistribution[] }
interface BusinessReviewFilters { sort, verified, withPhotos, branchId?, language?, rating? }
interface CreateBusinessReviewPayload { tenantId, branchId?, rating, title?, comment, ... }
interface ReviewAnalytics { averageRating, totalReviews, trend, replyRate, ... }
```

Key: entirely separate from `Review` in `src/types/index.ts` (menu item reviews) — zero interference.

## Phase C — Ratings Engine

**New file:** `src/services/business-review.service.ts`

```typescript
export const businessReviewService = {
  getBusinessReviews(tenantId, filters) → BusinessReviewsResponse
  getRatingBreakdown(tenantId, branchId?) → RatingBreakdownData
  createReview(payload) → BusinessReview
  replyToReview(reviewId, tenantId, text) → BusinessReview
  editReply(reviewId, tenantId, text) → BusinessReview
  deleteReply(reviewId, tenantId) → BusinessReview
  markHelpful(reviewId, tenantId) → { helpfulCount }
  moderateReview(reviewId, tenantId, status) → BusinessReview
  getReviewAnalytics(tenantId) → ReviewAnalytics
  _resetMockStore()
}
```

Rich mock data: 5 tenants × 2–5 reviews each. Reviews include: verified badges, owner replies, helpful counts, visit types, pinned state.

`buildBreakdown()` computes per-star distribution from the live review set.

## Phase L — Backend Contract
