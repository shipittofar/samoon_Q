## Changes

### New File: `src/utils/navigation-intelligence.ts`

Single source of truth for all navigation routing decisions. No component or utility duplicates this logic.

| Export | Purpose |
|---|---|
| `resolveWorkspace(role)` | Maps role → primary workspace URL |
| `resolveBestMenu(tenantSlug?)` | Tenant-aware menu URL |
| `resolveBestReservation(tenantSlug?)` | Tenant-aware reservation URL |
| `resolveBestBusiness(tenantSlug?)` | Best discover/menu URL |
| `resolveBestDashboardActions(tenantSlug?)` | Four quick-action items |
| `resolveFallbackRoute(isAuthenticated, role?)` | Safe fallback |
| `resolvePostLoginRedirect(role)` | Post-login destination |

### Role → Workspace Map

| Role | Workspace |
|---|---|
| `platform` | `/console/tenants` |

| `admin` | `/console` |

| `kitchen` | `/console/kitchen` |
| `staff` | `/console` |

| *(unknown)* | `/console` |

- Conditionally appended "Business Console" item to user dropdown menu
