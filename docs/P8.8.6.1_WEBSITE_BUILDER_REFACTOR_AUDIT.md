# P8.8.6.1 — Opinionated Website Builder Refactor Audit

## Overview

P8.8.6.1 refactors the generic free-form website builder (introduced in P8.8.6) into an "opinionated" builder where restaurant owners choose from curated presets instead of designing freely. The goal is to reduce decision fatigue and ensure consistently high-quality results.

---

## What Was Reused from P8.8.6

The following were preserved entirely and remain unchanged:

- **Section system** (`SectionConfig`, `SectionKey`, `SECTION_LABELS`, `DEFAULT_SECTIONS`) — enable/disable/reorder sections.
- **Version history** (`HomepageVersion`, versions array in `HomepageLayout`) — publish creates a snapshot; restore is supported.
- **Branch content overrides** (`BranchContentOverrides`, `useBranchOverrides`, `useSaveBranchOverrides`) — per-branch hero/description/phone_number overrides are untouched.
- **Publish/draft workflow** (`PublishStatus`, `lastPublishedAt`, `lastSavedAt`, `publishedVersion`) — same save/publish flow.
- **Service layer** — `src/services/website-builder.service.ts` is unchanged.
- **Hooks** — `src/hooks/index.ts` and all website builder hooks (`useHomepageLayout`, `useSaveLayout`, `usePublishLayout`, `useRestoreVersion`) are unchanged.
- **Legacy content types** — `HeroContent`, `AboutContent`, `ContactContent`, `FAQItem`, `ThemeSettings` are all still exported and in use.
- **RBAC** — `PermissionGuard permission="settings.view"` unchanged.
- **Routes and public URLs** — no route changes.

---

## What Was Replaced

| Old (P8.8.6)                          | New (P8.8.6.1)                          |
|---------------------------------------|-----------------------------------------|
| `ThemeTab` with free color pickers and font input | `ThemeTab` showing 10 curated `BrandThemeDef` cards with color swatch strips — click to select, no pickers |
| `HeroTab` with simple text/URL fields only | `HeroTab` with layout variant picker (A–E), background type pills, conditional URL inputs, alignment pills, CTA dropdowns, plus content fields |
| Separate About tab + separate Contact tab | Combined `ContentTab` with both About and Contact sections |
| 8 tabs total | 9 tabs total (Theme, Sections, Templates, Hero, Content, Modules, Preview, Branches, Versions) |
| No Templates tab | New `TemplatesTab` with pill selectors per section (Gallery/Reviews/Contact/About) |
| No Modules tab | New `ModulesTab` — read-only informational grid showing enabled features |

## What Was Added

### Types (`src/types/website-builder.ts`)

- `BrandThemeName` — union of 10 theme identifiers.
- `BrandThemeTokens` — structured token set (primary, accent, bg, fg, card, fgMuted, fontFamily, borderRadius, cardShadow).
- `BrandThemeDef` — full theme definition with name, label, description, tokens, and darkModePreference.
- `BRAND_THEMES` — catalog of 10 curated themes: elegant, modern, luxury, coffee, street_food, minimal, dark, fresh, family, premium.
- `DEFAULT_BRAND_THEME` — defaults to `'modern'`.
- `HeroLayoutVariant` — 5 layout options: hero_a through hero_e.
- `HeroBackgroundType` — image, video, gradient, solid.
- `HeroPrimaryCtaType` / `HeroSecondaryCtaType` — typed CTA options.
- `HeroConfig` — structured hero configuration replacing ad-hoc field editing.
- `HERO_LAYOUT_LABELS`, `HERO_PRIMARY_CTA_LABELS`, `HERO_SECONDARY_CTA_LABELS` — display label maps.
- `DEFAULT_HERO_CONFIG` — sensible default (hero_a, image, center, view_menu).
- `GalleryTemplate`, `ReviewsTemplate`, `ContactTemplate`, `AboutTemplate` — per-section template types.
- `SectionTemplates` — container for all 4 section template choices.
- `GALLERY_TEMPLATE_LABELS`, `REVIEWS_TEMPLATE_LABELS`, `CONTACT_TEMPLATE_LABELS`, `ABOUT_TEMPLATE_LABELS` — display maps.
- `DEFAULT_SECTION_TEMPLATES` — grid/cards/map_left/story_left defaults.

### Extended `HomepageLayout` (3 new optional fields)

```typescript
brandTheme?: BrandThemeName
heroConfig?: HeroConfig
sectionTemplates?: SectionTemplates
```

These are purely additive. All existing layouts that don't include these fields continue to work unchanged.

---

## Migration Path

**Existing data is fully backward compatible.** The three new fields (`brandTheme`, `heroConfig`, `sectionTemplates`) are all optional on `HomepageLayout`. Layouts saved before P8.8.6.1 will:

1. Render correctly in the admin UI — the new fields fall back to their defaults (`DEFAULT_BRAND_THEME`, `DEFAULT_HERO_CONFIG`, `DEFAULT_SECTION_TEMPLATES`).
2. Not require any data migration on the backend.
3. Continue to be served by the existing service layer without changes.

When an owner saves after opening the new builder, the new fields will be written alongside the existing fields.

---

## Deprecated Patterns

The following patterns are removed from the **admin UI** but remain in types for backward compatibility:

- **Free-form color pickers** — `ThemeSettings.primaryColor`, `ThemeSettings.accentColor`, `ThemeSettings.backgroundColor` are still exported types but no longer editable in the admin UI. The new `BrandTheme` system replaces them.
- **Free-form font input** — `ThemeSettings.fontFamily` is still a type field but no longer exposed in the admin UI. Font is now determined by the selected `BrandTheme`.
- **Separate About and Contact tabs** — merged into a single `Content` tab for a cleaner tab bar.

> The `ThemeSettings` interface, `ColorInput` helper, and related constants are retained in the type file to avoid breaking any services or third-party integrations that may reference them.
