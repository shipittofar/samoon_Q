# AUTH_DIFF_MATRIX.md

Every mismatch found in `AUTH_CONTRACT_AUDIT.md`, normalized to one row per defect, with root cause, severity, impact, and which side should change. Severity scale: **Critical** (endpoint unusable/security-relevant), **High** (endpoint usable only by accident or in a narrow case), **Medium** (silent data loss or type lie, no hard failure), **Low** (cosmetic/dead-code, no observable effect).

## UUID vs Integer check (explicitly requested)

Confirmed **no mismatch** in the Auth domain specifically: `User.id` is `models.UUIDField` backend-side; frontend's `User.id: string` accepts a UUID string natively. No integer/UUID conflict on any Auth/Profile field. (Note: this is domain-specific — other domains such as Places/Branches are known from `06_FRONTEND_BACKEND_CONTRACT_GAPS.md`/`10_API_CONTRACT_MATRIX.md` to have `place_id`-as-integer vs frontend `id: string` friction, but that is out of scope for this Auth-only audit.)
