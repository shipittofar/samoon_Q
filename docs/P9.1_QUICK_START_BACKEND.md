## Core Flows (Copy-Paste Ready)

### Phone Login → OTP → Existing User

```
1. POST /auth/phone/login
   ├─ Input: phone (E.164 format)
   ├─ Create challenge_id
   ├─ Generate 6-digit OTP
   ├─ Hash with bcrypt
   ├─ Store in otp_challenges table
   ├─ Queue SMS (async)
   └─ Return: challenge_id, expires_in: 300

2. POST /auth/otp/verify
   ├─ Input: challenge_id, otp_code
   ├─ Load otp_challenges by ID
   ├─ Check not expired (expires_at > now)
   ├─ Check attempt_count < max_attempts (3)
   ├─ Compare code vs hashed_otp (bcrypt)
   ├─ If match:
   │   ├─ Mark verified_at = now
   │   ├─ Bind to session_id (replay protection)
   │   ├─ Lookup user by phone
   │   ├─ Create session record
   │   ├─ Issue access + refresh tokens
   │   └─ Return: user, tokens, session, device_id
   └─ If mismatch:
       ├─ Increment attempt_count
       ├─ If attempt_count >= max:
       │   └─ Lock account, return 429
       └─ Else: return 401 with attempts_remaining

3. Tokens stored in localStorage
   ├─ access_token: 15 min TTL
   └─ refresh_token: 7 days TTL
```

### Email Login → OTP → New User

```
1. POST /auth/email/login
   ├─ Input: email
   ├─ Create challenge_id
   ├─ Generate OTP, hash, store
   ├─ Queue email (async)
   └─ Return: challenge_id, expires_in: 300

2. POST /auth/otp/verify
   ├─ Input: challenge_id, otp_code
   ├─ Verify (same as above)
   ├─ If match:
   │   ├─ Lookup user by email
   │   ├─ User NOT found → new user path
   │   ├─ Create registrations record (OTP_VERIFIED)
   │   ├─ Issue temp_token (1h TTL)
   │   └─ Return: is_new_user: true, next_step: "complete_profile"
   └─ temp_token used for next step

3. POST /auth/register/complete-profile
   ├─ Input: {first_name, last_name, email, accept_terms}
   ├─ Authorization: Bearer {temp_token}
   ├─ Create user record
   ├─ Create session + issue tokens
   └─ Return: user, tokens, session (same as login)
```

## Database Tables (Schema SQL)

### Essential Tables

```sql
-- Users (extend existing)
ALTER TABLE users ADD COLUMN phone VARCHAR(20) UNIQUE;
ALTER TABLE users ADD COLUMN email VARCHAR(255) UNIQUE;
ALTER TABLE users ADD COLUMN phone_verified_at TIMESTAMP;
ALTER TABLE users ADD COLUMN email_verified_at TIMESTAMP;
ALTER TABLE users ADD COLUMN is_locked BOOLEAN DEFAULT false;
ALTER TABLE users ADD COLUMN locked_until TIMESTAMP;

-- OTP Challenges
CREATE TABLE otp_challenges (
  id UUID PRIMARY KEY,
  contact VARCHAR(255) NOT NULL,
  contact_type ENUM('phone', 'email') NOT NULL,
  hashed_otp VARCHAR NOT NULL,
  attempt_count INTEGER DEFAULT 0,
  max_attempts INTEGER DEFAULT 3,
  created_at TIMESTAMP NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  verified_at TIMESTAMP,
  verified_by_session_id UUID,
  used_at TIMESTAMP,
  cancelled_at TIMESTAMP
);
CREATE INDEX idx_otp_contact ON otp_challenges(contact, contact_type, expires_at DESC);
CREATE INDEX idx_otp_expires ON otp_challenges(expires_at);

-- Registrations
CREATE TABLE registrations (
  id UUID PRIMARY KEY,
  contact VARCHAR(255) NOT NULL,
  contact_type ENUM('phone', 'email') NOT NULL,
  status ENUM('PENDING', 'OTP_SENT', 'OTP_VERIFIED', 'PROFILE_PENDING', 'COMPLETED', 'EXPIRED', 'CANCELLED', 'BLOCKED') NOT NULL,
  challenge_id UUID REFERENCES otp_challenges(id),
  first_name VARCHAR(100),
  last_name VARCHAR(100),
  email VARCHAR(255),
  temp_token VARCHAR,
  user_id UUID REFERENCES users(id),
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL,
  expires_at TIMESTAMP
);
CREATE INDEX idx_registrations_status ON registrations(status, created_at);
CREATE UNIQUE INDEX idx_registrations_contact ON registrations(contact, contact_type) WHERE deleted_at IS NULL;

-- Sessions
CREATE TABLE sessions (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES users(id),
  device_id UUID NOT NULL,
  status ENUM('ACTIVE', 'INACTIVE', 'REVOKED', 'EXPIRED') NOT NULL,
  ip_address VARCHAR(45) NOT NULL,
  user_agent VARCHAR NOT NULL,
  device_name VARCHAR(255),
  device_type ENUM('mobile', 'desktop', 'tablet', 'unknown'),
  country VARCHAR(2),
  created_at TIMESTAMP NOT NULL,
  last_activity_at TIMESTAMP NOT NULL,
  expires_at TIMESTAMP,
  logged_out_at TIMESTAMP,
  revoked_at TIMESTAMP
);
CREATE INDEX idx_sessions_user ON sessions(user_id, status, last_activity_at DESC);
CREATE INDEX idx_sessions_device ON sessions(device_id);

-- Login Attempts
CREATE TABLE login_attempts (
  id UUID PRIMARY KEY,
  contact VARCHAR(255),
  contact_type ENUM('phone', 'email'),
  user_id UUID REFERENCES users(id),
  attempt_result ENUM('SUCCESS', 'FAILED', 'LOCKED') NOT NULL,
  failure_reason VARCHAR,
  ip_address VARCHAR(45) NOT NULL,
  user_agent VARCHAR,
  device_id UUID,
  country VARCHAR(2),
  fraud_risk_score INTEGER DEFAULT 0,
  created_at TIMESTAMP NOT NULL
);
CREATE INDEX idx_login_contact ON login_attempts(contact, created_at DESC);
CREATE INDEX idx_login_user ON login_attempts(user_id, created_at DESC);

-- Token Blacklist
CREATE TABLE refresh_token_revocations (
  jti VARCHAR PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES users(id),
  session_id UUID REFERENCES sessions(id),
  token_family_id VARCHAR,
  reason VARCHAR NOT NULL,
  revoked_at TIMESTAMP NOT NULL,
  expires_at TIMESTAMP
);
CREATE INDEX idx_blacklist_user ON refresh_token_revocations(user_id, revoked_at DESC);

-- Audit Logs
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY,
  event_type VARCHAR NOT NULL,
  user_id UUID REFERENCES users(id),
  session_id UUID REFERENCES sessions(id),
  ip_address VARCHAR(45),
  details JSONB,
  severity ENUM('info', 'warning', 'critical') DEFAULT 'info',
  created_at TIMESTAMP NOT NULL
);
CREATE INDEX idx_audit_user ON audit_logs(user_id, event_type, created_at DESC);
```

## Critical Implementation Details

### OTP Storage & Hashing

```typescript
// NEVER store plaintext OTP
const code = generateOTP(6);  // "123456"
const hash = await bcrypt.hash(code, 10);
// Store ONLY hash in database

// On verify:
const isValid = await bcrypt.compare(submittedCode, storedHash);
```

### Token Structure

```typescript
// Access Token (15 min)
{
  "type": "access",
  "sub": "{user_id}",
  "iat": 1234567890,
  "exp": 1234569090,  // iat + 900 seconds
  "session_id": "{session_uuid}",
  "device_id": "{device_uuid}",
  "roles": ["customer"],
  "token_family": "{family_id}"
}

// Refresh Token (7 days)
{
  "type": "refresh",
  "sub": "{user_id}",
  "iat": 1234567890,
  "exp": 1234567890 + (7 * 86400),
  "session_id": "{session_uuid}",
  "token_family": "{family_id}",
  "jti": "{unique_id}"
}
```

### Replay Protection (Critical!)

```typescript
// On OTP verify:
const verified = await bcrypt.compare(code, challenge.hashed_otp);
if (verified) {
  // IMPORTANT: Bind OTP to this session
  challenge.verified_by_session_id = currentSessionId;
  await saveChallengeVerification();
  
  // Issue tokens for THIS session
  const tokens = issueTokens(userId, currentSessionId);
  return tokens;
}

// On subsequent requests:
const sessionIdFromToken = decodeJWT(accessToken).session_id;
const sessionIdFromRequest = getOrCreateSessionId();  // from cookie/header
if (sessionIdFromToken !== sessionIdFromRequest) {
  return 401 Unauthorized;
}
```

### Rate Limiting (Redis Pattern)

```typescript
// Key: "{operation}:{contact}:{window_start}"
// Example: "otp_send:+1234567890:2026-07-05"

async function checkRateLimit(contact: string, operation: string, limit: number, windowSeconds: number) {
  const key = `ratelimit:${operation}:${contact}`;
  const current = await redis.incr(key);
  
  if (current === 1) {
    // First attempt in window, set TTL
    await redis.expire(key, windowSeconds);
  }
  
  if (current > limit) {
    return { allowed: false, retryAfter: await redis.ttl(key) };
  }
  
  return { allowed: true };
}
```

### Session Binding

```typescript
// Every API request includes session context
async function extractSessionFromRequest(req) {
  const token = req.headers.authorization?.split(' ')[1];
  const decoded = jwt.decode(token);
  
  const sessionIdFromToken = decoded.session_id;
  const sessionIdFromCookie = req.cookies['session_id'];
  
  // Both must match
  if (sessionIdFromToken !== sessionIdFromCookie) {
    throw new UnauthorizedException('Session mismatch');
  }
  
  return sessionIdFromToken;
}
```

## Common Debugging Patterns

**User can't log in:**
1. Check `login_attempts` table for failure_reason
2. Check if contact is in a blocked IP list
3. Check if account is locked (`users.is_locked = true`, `locked_until > now`)
4. Check rate limit in Redis: `redis-cli GET ratelimit:login_attempt:{contact}`
5. Check OTP cache: `redis-cli GET otp:{challenge_id}`

**Tokens not working:**
1. Verify `Authorization: Bearer {token}` format
2. Check token expiration: `jwt.decode(token).exp > now()`
3. Check session binding: token.session_id must match request session_id
4. Check if token in blacklist: query `refresh_token_revocations` by jti
5. Check if session revoked: `sessions.status = 'REVOKED'`

**High fraud scores:**
1. Check `login_attempts.fraud_flags` column (JSON array of reasons)
2. Check `login_attempts.country` vs user's typical country
3. Check IP reputation: query `ip_reputation_cache`
4. Check impossible travel: distance / time = speed > 900 km/h?
5. Check device fingerprint changes: new device detected?

## Performance Optimization Tips

1. **Index hot paths:**
   ```sql
   -- OTP lookups (every login)
   CREATE INDEX idx_otp_contact ON otp_challenges(contact, contact_type, expires_at DESC);
   
   -- Session checks (every API request)
   CREATE INDEX idx_sessions_user_active ON sessions(user_id) WHERE status = 'ACTIVE';
   ```

2. **Use Redis for rate limits, not database:**
   ```
   Atomic Redis INCR >> Database UPDATE lock
   ```

3. **Batch token blacklist cleanup:**
   ```sql
   -- Once daily, not per-request
   DELETE FROM refresh_token_revocations WHERE expires_at < NOW();
   ```

4. **Cache config with short TTL:**
   ```
   Redis cache: auth_config with 5-minute TTL
   Invalidate on admin change via pubsub event
   ```

5. **Async SMS/Email:**
   ```
   [Request] → Queue task → Return immediately
   [Worker] → Send SMS/Email slowly in background
   ```
