## 3. Storage Strategy

| Data | Storage Location |
|------|-----------------|
| `HomepageLayout` (sections, hero, about, contact, faq, theme) | `tenant.settings.websiteBuilder` |
| Branch content overrides | `tenant.settings.branchOverrides[branchSlug]` |
| Version history | `HomepageLayout.versions[]` (last 10) |

No new database tables required — all stored in the existing `tenant.settings` JSON blob.
