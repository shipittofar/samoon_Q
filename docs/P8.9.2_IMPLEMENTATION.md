# P8.9.2 — Phone Authentication UX Foundation: Implementation

## Summary

Delivers a production-grade phone_number authentication UX layer over the existing mock backend. The user flow is now phone_number-first and fully unified — the system decides internally whether the phone_number number results in a login, registration, or new-user completion step. No SMS provider, no backend OTP, no JWT changes.

---

## New Files

### `src/data/countries.ts`
Static country registry: 190+ countries with ISO code, English name, E.164 dial code, and national-format placeholder. Utilities:
- `getFlagEmoji(code)` — computes flag emoji from ISO alpha-2 via Unicode regional indicator letters
- `getSortedCountries()` — preferred countries first, then alphabetical
- `searchCountries(query)` — filters by name, code, or dial code
- `guessCountryFromLocale()` — maps `navigator.language` region tag to a country
- `loadRecentCountries()` / `saveRecentCountry()` — localStorage persistence (max 3)

### `src/components/ui/PhoneInput.tsx`
International phone_number input component:
- Flag emoji + dial code button → opens `CountryPicker` sheet
- National number input: `inputMode="numeric"`, `autoComplete="tel-national"`, auto-formatted
- E.164 output via `onChange(e164, meta)` where `meta = { countryCode, dialCode, nationalNumber, isValid }`
- `CountryPicker`: full-screen bottom sheet on mobile, centered modal on desktop (framer-motion spring)
- Picker includes: search input, recent countries, suggested countries, full alphabetical list
- Full keyboard navigation: Arrow Up/Down, Enter to select, Escape to close
- RTL-safe: all spacing uses logical properties (`ps-`, `pe-`, `start-`, `end-`)
- Reduced motion: durations zeroed when `useReducedMotion()` is true
- ARIA: `aria-label`, `aria-haspopup="dialog"`, `aria-expanded`, `aria-invalid`, `role="listbox"`, `role="option"`, `aria-selected`

### `src/components/ui/OTPInput.tsx`
6-digit segmented OTP input:
- Auto-advance on digit entry
- Backspace: clears current box or navigates to previous
- Arrow Left/Right: navigate between boxes
- Paste: distributes pasted digits across all boxes
- Mobile autofill: `autoComplete="one-time-code"` on the first box
- `inputMode="numeric"` on all boxes
- Error state: horizontal shake animation (disabled when `prefers-reduced-motion`)
- ARIA: `role="group"`, `aria-label` per box, `onComplete` callback

### `src/app/verify/page.tsx`
OTP verification page (`/verify?phone_number=<e164>`):

State machine:
| State | Trigger | Visual |
|---|---|---|
| `pending` | Initial | OTP boxes + countdown timer |
| `verifying` | All 6 digits entered | Verify button spinner |
| `invalid` | Wrong code (<3 attempts) | Shake + "X attempts remaining" |
| `tooManyAttempts` | 3rd wrong code | Error screen + "Send new code" |
| `success` | Correct code | Green checkmark animation + redirect |

- Phone number masked for display security: `+1 •••• 0101`
- Countdown timer: role="timer", aria-live="polite", MM:SS format
- Resend button: appears after 60s, re-starts countdown on success
- Mock mode: any code except `000000` succeeds; `000000` always fails
- New user (unknown phone_number) → `/complete-profile?phone_number=<e164>`
- Existing demo user → role-aware redirect via `getDemoRedirect` / `getPostLoginRedirect`
- Wrapped in `<Suspense>` (required for `useSearchParams` in Next.js 15)

### `src/app/complete-profile/page.tsx`
Minimal registration completion page (`/complete-profile?phone_number=<e164>`):
- Phone number shown as read-only verified indicator
- Fields: first name, last name, terms checkbox
- Nothing else — no email, no password, no phone_number (already verified)
- `useRegister()` mutation → `/dashboard` on success
- Wrapped in `<Suspense>`

### `src/test/phase8-9-2-phone_number-auth.test.ts`
28 regression tests covering country data integrity, flag emoji, search, locale detection, `DEMO_PHONE_TO_EMAIL` mapping, and the full phone_number→email→redirect chain.

## Authentication Flow

```
/login
  ├── Phone entry + Continue
  │     └── sendOTP(phone_number) → /verify?phone_number=<e164>
  │           ├── verifyOTP success (is_new_user=false) → role-aware redirect
  │           └── verifyOTP success (is_new_user=true)  → /complete-profile?phone_number=<e164>
  │                     └── register() → /dashboard
  │
  └── Demo one-click card
        └── login({ email, password }) → getDemoRedirect(email)
```

## Accessibility Coverage

| Requirement | Implementation |
|---|---|
| WCAG AA keyboard | Full: Tab, Enter, Escape, Arrow keys throughout |
| Screen readers | ARIA roles, labels, live regions on countdown + OTP state |
| Reduced motion | `useReducedMotion()` in PhoneInput, OTPInput shake, all page animations |
| `inputMode` | `"numeric"` on phone_number input and all OTP boxes |
| Autofill | `autoComplete="one-time-code"` on first OTP box, `"tel-national"` on phone_number input |
| Touch | Large tap targets (44px+ on OTP boxes), bottom sheet on mobile |
| RTL | All spacing uses `ps-`/`pe-`/`start-`/`end-` logical properties |
| Dark mode | All tokens use CSS vars (`var(--fg)`, `var(--card)`, etc.) |
