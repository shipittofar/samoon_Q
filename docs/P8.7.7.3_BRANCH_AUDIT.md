# P8.7.7.3 — Enterprise Public Branch Experience: Pre-Implementation Audit

## 1. Current Route Architecture

### `/[tenantSlug]/[branchSlug]` — Status: STUB
`src/app/[tenantSlug]/[branchSlug]/page.tsx` simply re-exports from `/app/restaurant/page` (the generic restaurant overview). No branch-specific hero, info, or sections exist.

### `/[tenantSlug]/[branchSlug]/layout.tsx` — CORRECT
- Reads `tenantSlug` and `branchSlug` from async params (Next.js 15 API).
- Calls `loadTenant(tenantSlug)` when slug changes.
- Calls `useAdminBranches(tenant?.id)` to fetch branches.
- Finds matching branch by `b.slug === branchSlug`, then sets:
  - `setAdminActiveBranch(match)` — P7.3 admin domain model
  - `setActiveBranch(adminBranchToPublic(match))` — customer-facing Location alias
- **Bug exposed**: `useAdminBranches` calls `branchManagementService.getBranches(tenantId)`, which filters by `b.tenantId === tenantId`. All 12 mock branches currently have `tenantId: 'tenant-savor-01'`, so visiting `/brew-cafe/main` returns an empty array and never sets branch context.

### Sub-routes — all thin re-exports
| Route | Current Implementation |
|---|---|
| `/[tenantSlug]/[branchSlug]/menu` | Renders `MenuContent` |
| `/[tenantSlug]/[branchSlug]/reservation` | Re-exports `/app/reservation/page` |
| `/[tenantSlug]/[branchSlug]/loyalty` | Re-exports `/app/loyalty/page` |
| `/[tenantSlug]/[branchSlug]/promotions` | Re-exports `/app/promotions/page` |
| `/[tenantSlug]/[branchSlug]/events` | Re-exports `/app/events/page` |

## 5. MarketplaceMeta & PublicBranchInfo

`PublicBranchInfo` (src/types/marketplace.ts):
```ts
{ slug, name, address, city, phone_number?, openNow, todayHours?, image? }
```

`getMarketplaceMeta(settings)` safely extracts the `marketplace` field from tenant settings.

Each tenant's `marketplace.branches` array is the ground-truth public branch list. This is the correct data source for the public branch homepage — avoids the `MOCK_TENANT_ID` issue entirely for read operations.

## 6. Hook Gap

Missing: `usePublicBranch(tenantSlug, branchSlug)` — isolated query key `['public-branch', tenantSlug, branchSlug]`. Must look up from `marketplace.branches`, not from `branchManagementService` (which is admin-only).

## 7. Not-Found Gap

## 10. Implementation Plan

### Step 1: Fix branch.service.ts mock data
- Fix `tenantId` for cafe, bar, food-court, mobile-cafe branches
- Fix slugs to match `marketplace.branches` slugs

### Step 2: Add `usePublicBranch` hook
- Query key: `['public-branch', tenantSlug, branchSlug]`
- Source: `tenantService.getTenant(tenantSlug)` → `getMarketplaceMeta` → find by slug
- Returns `null` for unknown tenants or unknown branch slugs

### Step 3: Create `BranchHomepageClient.tsx`
- Hero: branch image, name, tenant name, open/closed badge, rating
- Breadcrumb: Discover → Business → Branch
- Quick Actions: View Menu, Reserve Table, Order Online, Call, Share, Copy URL
- Branch Info: address, phone_number, email, hours table, facilities
- Branch Switcher: shown when tenant has >1 branch
- Sections: Featured Menu Items, Categories, Promotions, Reviews, Gallery, Nearby Branches
- Analytics context: tenantSlug + branchSlug + branchId exposed

### Step 4: Create `page.tsx` (server component)
- `generateMetadata` with branch-specific title/description/OG/Twitter/canonical
- Structured data (LocalBusiness JSON-LD)
- Call `notFound()` for unknown tenant or unknown branch slug

### Step 5: Create `not-found.tsx`
- Branch-specific 404 with link back to tenant homepage + /discover

### Step 6: Write tests
- `src/test/branch-homepage.test.ts`
- Covers: `usePublicBranch` behavior, mock data correctness, branch slug resolution
