## Phase-by-Phase Breakdown

### Phase A — Audit
`docs/P8.8.2_LANDING_AUDIT.md` — full section-by-section audit with REMOVE / REPLACE / KEEP decisions.

### Phase B — New Hero

**Before:** "Extraordinary Flavors, Delivered" with restaurant dining room background, Order Now + Reserve a Table CTAs.

**After:**
- Headline: "Find Great Restaurants Near You"
- Subheadline: multi-business marketplace description
- Live search form (`<form action="/discover" method="GET">`) — works without JS
- Category chips: Restaurant | Café | Bar | Food Truck | Food Court → `/discover?category=*`
- Primary CTA: **Explore Businesses** → `/discover`
- Secondary CTA: **Become a Partner** → `/restaurant`
- Background: marketplace-appropriate crowd/food-court image
- Pill badge: "500+ businesses on Samoon" (replaces "Now open for delivery")

**Test constraints satisfied:**
- `<Image fill sizes="100vw">` preserved
- No `useQuery`, no `useMenuItems`

### Phase C — Discovery Preview

New `DiscoveryPreview` component renders 6 mock business cards (based on actual tenant slugs: samoon, brew-cafe, the-oak-bar, central-food-court, wheels-and-brews, road-bites). Each card links to `/{slug}` and shows: business name, type label, rating, review count, location, price level, badge. View All CTA → `/discover`.

### Phase D — Business Categories

`const CATEGORIES` in `page.tsx` (test-required constant) now contains business types instead of food categories:
- Restaurants, Cafés, Bars, Food Courts, Food Trucks
- All links → `/discover?category=*` (was `/menu?category=*`)

### Phase E — How It Works

`HowItWorks` component: 3 numbered steps with icons — Discover → Choose a Branch → Order or Reserve. Desktop shows a horizontal connector line.

### Phase F — For Business Owners

`ForBusinessOwners` component:
- Left: headline, description, 3 CTAs (Register Business, Learn More, Admin Preview)
- Right: 6-item benefits grid (Analytics, QR Ordering, Staff/RBAC, Loyalty, Multi-Branch, Kitchen Display)

### Phase G — Platform Features

`PlatformFeatures` component: 10-item grid of platform capabilities — Online Menu, Reservations, QR Ordering, Loyalty, Analytics, Kitchen Display, POS Integration, Multi-Branch, Gift Cards, Events.

### Phase H — Footer Extended

Added to footer link sections:
- Explore: Food Trucks link
- Platform: Become a Partner, Pricing (both → /restaurant)
- Company: Support, Terms of Service (both → /privacy)

### Phase I — Platform Navigation

`Header.tsx` now detects root site context:
```typescript
const moduleNav = useModuleNav()
const navLinks = tenant.slug === 'default' ? PLATFORM_NAV : moduleNav
```

`PLATFORM_NAV` provides:
- **Discover** → `/discover`
- **Reservations** → `/reservation`
- **About** → `/restaurant`

Tenant-specific navigation (Menu, Reviews, Loyalty, etc.) is unchanged — still shown when a real tenant is active.

### Phase J — Marketplace Metrics Component

`PlatformStats` is a reusable, typed component:
```tsx
<PlatformStats stats={[
  { value: '500+', label: 'Businesses' },
  { value: '50+', label: 'Branches' },
  ...
]} />
```

The `const STATS` in `page.tsx` (test-required) now holds platform metrics: Businesses, Branches, Cities, Customers (was: Menu Items, Rating, Delivery time).

### Phase K — Animations

No new animation libraries added. Existing Framer Motion in the Header is unchanged. New sections use CSS transitions only (`hover:-translate-y-1`, `transition-all duration-300`).

### Phase L — Responsive

All new components use the same Tailwind responsive grid pattern as the rest of the codebase:
- Mobile: single column or 2-column grid
- Tablet (`sm:`): 2–3 columns
- Desktop (`lg:`): 3–5 columns
- Max-width container: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`

### Phase M — SEO

`page.tsx` metadata is unchanged from P8.8.1 (already marketplace-correct):
- title: "Samoon — Discover Local Businesses"
- description: marketplace description
- OG siteName: 'Samoon Platform'
- JSON-LD: `DEFAULT_PLATFORM_JSON_LD` (WebSite + SearchAction)
