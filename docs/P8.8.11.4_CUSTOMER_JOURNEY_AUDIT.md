# P8.8.11.4 — Customer Journey Audit

## Scope

Every public customer flow across: Landing / Discover · Tenant Homepage · Branch Homepage · Menu · Reservation · Checkout · Gallery · Reviews · Promotions · Loyalty · Footer · Navigation · Hero CTAs · Quick Actions · Breadcrumbs · Empty States.

---

## Identified Gaps

### J1 — Static CTA Order (CRITICAL)
**Files:** `TenantHomepageClient.tsx`, `BranchHomepageClient.tsx`  
**Problem:** QuickActions rendered CTAs in a hardcoded order: Menu → Locations → Reservation → Loyalty. A food truck's most important CTA ("Where is the truck today?") was buried. A restaurant's reservation CTA appeared after the menu link.  
**Impact:** Wrong conversion path for every non-restaurant business type.  
**Fix (Phase D):** `buildCustomerJourney()` reorders CTAs by business type. Food truck: Locations → Menu. Restaurant/Bar: Reservation → Menu. Cafe: Menu → Loyalty.

### J2 — Static Section Order (HIGH)
**Files:** `TenantHomepageClient.tsx`, `BranchHomepageClient.tsx`  
**Problem:** Both homepage clients rendered sections in a fixed order regardless of business type: About → Reviews → Gallery → Branches → [Categories] → FeaturedMenu → Promotions. A food truck restaurant showing "About" before the truck's current location is a UX dead end.  
**Impact:** Users had to scroll past irrelevant sections to find key information.  
**Fix (Phase F):** `journey.sectionOrder` drives render order. Food truck: Branches (location) → FeaturedMenu → Promotions → About. Restaurant: FeaturedMenu → Reviews → About.

### J3 — Nav Order Ignores Business Type (MEDIUM)
**Files:** `navigation.ts` (`buildTenantNavigation`)  
**Problem:** Nav links appeared in module registry order (alphabetical by module key), not by customer intent. A food truck's "Locations" link appeared after "Menu" even though finding the truck is the primary intent.  
**Impact:** Customers had to hunt for the most important nav item.  
**Fix (Phase E):** `buildTenantNavigation()` accepts `journeyNavPriority` from `buildCustomerJourney()`. Applied when Website Builder has no ordering config. Food truck priority: Locations → Menu → Order.

### J4 — Hero CTA Already Good (LOW)
**Files:** `navigation.ts` (`getSmartCTA`)  
**Problem:** None — `getSmartCTA` already handles multi-branch, reservation-first, ordering-first priority correctly and produces the right hero CTA for all current cases.  
**Status:** No change needed. Journey engine's `primaryCTA` handles QuickActions; `getSmartCTA` continues to drive the hero.

### J5 — Food Truck / Mobile Cafe: No "Current Location" Emphasis (HIGH)
**Files:** Both homepage clients, `navigation.ts`  
**Problem:** Food trucks and mobile cafes have no distinct "today's location" UX. The Branches section was rendered 5th (after About, Reviews, Gallery), which is a dead-end journey for customers who don't know where to find the truck.  
**Impact:** High bounce rate from food truck pages.  
**Fix:** `sectionOrder` for food_truck/mobile_cafe starts with `branches` so location is immediately visible.

### J6 — Hotel/Venue: Story Buried Under Menu Items (MEDIUM)
**Files:** Both homepage clients  
**Problem:** Hotels showed `FeaturedMenu` before `About`, but hotels sell experience/story first.  
**Fix:** Hotel profile: `about → featured_menu → reviews → gallery`.

### J7 — Cafe: Promotions Not Prominent (MEDIUM)
**Files:** Both homepage clients  
**Problem:** Promotions (daily specials, happy hour, deals) are a key conversion driver for cafes, but appeared last in the section order.  
**Fix:** Cafe profile: `featured_menu → promotions → about → reviews`.

### J8 — Bar: Events Not Surfaced in Nav Priority (LOW)
**Files:** `navigation.ts`  
**Problem:** Bar tenants with events enabled had no nav priority hint to surface events above other items.  
**Fix:** Bar nav priority: `menu → reservation → events → gallery`.

### J9 — No Single Source of Journey Truth (CRITICAL)
**Files:** Both homepage clients  
**Problem:** CTA resolution logic was duplicated across `QuickActions` in both homepage clients. Each called `buildPublicCTAs` and rendered in hardcoded order independently.  
**Impact:** Any change to CTA logic required updating two files.  
**Fix:** Both clients now compute `journey` once and pass it to `QuickActions`. Zero duplication.

## Business Type Journey Profiles

| Type | Primary CTA | Section Order Start | Nav Priority Start |
|------|-------------|--------------------|--------------------|
| restaurant | Reserve (if enabled) → Menu | featured_menu → reviews → about | menu → reservation |
| cafe | Menu | featured_menu → promotions → about | menu → loyalty |
| bar | Reserve (if enabled) → Menu | featured_menu → about → reviews | menu → reservation → events |
| food_truck | Locations (if multi-branch) → Menu | branches → featured_menu → promotions | locations → menu |
| mobile_cafe | Locations (if multi-branch) → Menu | branches → featured_menu → promotions | locations → menu → loyalty |
| food_court | Locations (if multi-branch) → Menu | branches → featured_menu → about | locations → menu |
| hotel | Reserve (if enabled) → Menu | about → featured_menu → reviews | menu → reservation |
| other | Menu | featured_menu → about → reviews | menu → reservation |

## Flows with No Issues Found

- **Breadcrumbs:** Correct hierarchy on both homepage pages (Discover › Tenant › Branch).
- **Empty states:** BranchNotFound and TenantNotFoundState both present with correct CTAs.
- **Deep links:** Section anchor `#branches` works correctly for multi-branch Locations CTAs.
- **SEO:** Metadata and JSON-LD builders are not affected by journey ordering.
- **Website Builder:** `layoutNavConfig` still takes full precedence over `journeyNavPriority` when an owner has configured custom nav ordering.
- **Feature flags:** `buildPublicCTAs` (called before `buildCustomerJourney`) still gates all CTAs correctly. Journey engine never re-resolves flags.
- **Preview mode:** Journey ordering works identically in preview — section rendering is structural, not server-driven.
