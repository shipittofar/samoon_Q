# P8.8.4 — Marketplace Discovery & Search Experience: Implementation

> **SUPERSEDED (cuisines / amenities):** Search/filter cuisine & amenity values
> come from **Branch** data (`collectBranchCuisines` / `collectBranchAmenities`).
> Not from `meta.cuisines` / `meta.amenities`. See `docs/BACKEND_API_CONTRACT.md` §30.4.

## Overview

Transforms `/discover` from a basic sectioned listing into a full marketplace search experience with rich filtering, sorting, improved cards, branch previews, curated collections, and helpful empty states.

## Phase B — Search Expansion

**File:** `src/types/marketplace.ts`

Extended `matchesSearch()` to cover additional fields without changing the function signature:

```typescript
// Added accent-insensitive normalization:
function normalize(s: string): string {
  return s.toLowerCase().normalize('NFD').replace(/\p{M}/gu, '')
}

// Added to matchesSearch():
(meta.tagline ? normalize(meta.tagline).includes(q) : false) ||
(meta.amenities ?? []).some((a) => normalize(a).includes(q)) ||
(meta.branches ?? []).some((b) => normalize(b.name).includes(q))
```

All existing `matchesSearch` tests continue to pass (tested with `café` → `cafe` normalization).

## Phase C — Advanced Filters

**New file:** `src/components/marketplace/AdvancedFilters.tsx`

**New type:** `FilterState` in `src/types/marketplace.ts`:
```typescript
interface FilterState {
  cuisines: string[]      // multi-select, OR logic within group
  cities: string[]        // multi-select, OR logic within group
  priceLevels: number[]   // 1–4, OR logic within group
  openNow: boolean        // AND logic with other filters
  services: string[]      // feature flag keys
  amenities: string[]     // AND logic (must have ALL selected amenities)
}
```

**New function:** `matchesFilters(meta, featureFlags, filters)` — applies all filter dimensions. Services check: `reservations.enabled` exact match; loyalty checks any flag key containing `'loyalty'`.

**New helpers:** `hasActiveFilters()`, `countActiveFilters()`, `DEFAULT_FILTERS`.

**Available filter options** are derived dynamically from the live tenant list in `useMemo` hooks within `DiscoverClientPage`.

## Phase H — Featured Collections

**File:** `src/app/discover/DiscoverClientPage.tsx`

Collections computed from live data via `useMemo`:

| Collection | Criteria |
|-----------|---------|
| Featured | `meta.featured === true` |
| Popular Right Now | `meta.popular === true && !meta.featured` |
| Newly Opened | `meta.isNew === true` |
| Top Rated | `meta.rating >= 4.5`, sorted by rating |
| Family Friendly | `meta.tags.includes('Family Friendly')` |
| Coffee Shops | `businessTypes ∩ ['cafe', 'mobile_cafe'] ≠ ∅` |
| All Businesses | All tenants, user-selected sort |

Sections are hidden when empty (null return from `Section` component).
