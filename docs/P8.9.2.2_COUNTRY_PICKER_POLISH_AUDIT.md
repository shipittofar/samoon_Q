## P8.9.2.2 Changes

### Phase B — Pinned Countries
- New `PINNED_COUNTRY_CODES` export: `['US', 'GB', 'DE', 'FR', 'CA', 'AU', 'AE', 'TR', 'IR', 'AZ']`
- New `getPinnedCountries()` — memoized; returns Country[] in display order
- New `getRestCountries()` — memoized; all countries except pinned, alphabetical
- Pinned section always shown first when not searching
- Pinned countries NOT included in "All countries" section — zero duplication
- Label: "Pinned" (was "Suggested")

### Phase C — Recent Countries
- `MAX_RECENT` increased from 3 → 5
- `loadRecentCountries()` now filters out pinned countries so recent never duplicates pinned
- `recentFiltered` computed in picker, also filtered against pinned set
- "All countries" section additionally filters out recents
- Section order: Pinned → Recent (if any) → All

### Phase D — Better Auto Detection
- New `LAST_SELECTED_KEY = 'phone-input-last-selected'` localStorage key
- New `saveLastSelected(code)` — called on every country selection
- New `loadLastSelected()` — called in `resolveInitialCountry`
- New `guessCountryFromTimezone()` — 70+ timezone→country mappings via `Intl.DateTimeFormat`
- Detection priority in `resolveInitialCountry`:
  1. `defaultCountry` prop
  2. Parsed from `value` (E.164)
  3. `loadLastSelected()` (localStorage)
  4. `guessCountryFromLocale()` (navigator.language)
  5. `guessCountryFromTimezone()` (Intl)
  6. US fallback

### Phase E — Premium Search
- New `normalizeQuery(s)` — exported, accent-strip + lowercase
- New `scoreCountry(country, q)` — scoring function:
  - 100: exact name/code/dialCode match
  - 80: starts-with match
  - 60: contains match
  - 55: dial code contains (≥2 digits)
  - 50: any word starts with query
  - 20: subsequence fuzzy match (≥3 char queries only)
  - 0: no match
- `searchCountries()` now ranks by score descending, then alphabetical
- Dial code search: strips leading `+`, matches both `"44"` and `"+44"`

### Phase F — Keyboard Navigation
- PageDown: jump +8 rows
- PageUp: jump -8 rows
- Home: go to first item
- End: go to last item
- Type-to-search: printable character typed while not in search field → focus search + append
- `navList` is a unified flat array for keyboard nav (pinned + recent + rest, or search results)

### Phase G — Active Row Experience
- `optionId(i)` generates stable per-option IDs
- `aria-activedescendant` on both search input and listbox, pointing to active option ID
- Scroll-into-view on `activeIndex` change using option ID lookup
- Auto-scroll to selected country on open via `data-selected="true"` attribute

### Phase H — Visual Hierarchy
- Selected row: `bg-[var(--accent)]/10` + left accent border (`border-s-2 border-[var(--accent)]`)
- Keyboard-active row: `bg-[var(--accent)]/15` + ring
- Checkmark SVG on selected (no Lucide dependency for the check)
- ISO code shown with `hidden sm:inline` — visible on tablets and up
- Dial code always `dir="ltr"` for RTL layout compatibility

### Phase I — Empty State
- Emoji icon + heading + helper text
- "Clear search" button (both inline and in empty state)
- Inline clear `X` button in search input when query is non-empty

### Phase J — Animations
- Backdrop: 0.18s fade (was 0.2s — slightly crisper)
- Sheet: spring (damping 30, stiffness 300) — unchanged
- `prefers-reduced-motion` disables all transitions

### Phase K — Scrollbar
- WebKit scrollbar: 5px wide, transparent track, rounded thumb using CSS variable `[var(--border)]`
- Hover state: thumb darkens to `[var(--fg-muted)]`

### Phase L — Accessibility
- `useAnnouncer()` — `role="status" aria-live="polite" aria-atomic="true"` div (sr-only)
- Announces: picker opened / N countries found / No countries found / {Country} selected
- `aria-labelledby={titleId}` wired to `<h2>`
- `aria-activedescendant` on both `<input>` and `[role=listbox]`
- `aria-controls` on search input pointing to list ID
- `aria-autocomplete="list"` on search input

### Phase M — RTL
- Dial codes wrapped in `dir="ltr"` on both the trigger button and each row
- Country names and ISO codes use natural text direction

### Phase N — Performance
- `getPinnedCountries()` — memoized (module-level cache)
- `getRestCountries()` — memoized (module-level cache)
- `getAlphaCountries()` — new memoized alphabetical list
- `getSortedCountries()` — continues to use module-level cache
- `results`, `pinned`, `recentFiltered`, `rest`, `navList` all use `useMemo`
