## 3. Gap Analysis (Before → After)

| Feature | Before | After |
|---------|--------|-------|
| Business-level reviews | Hardcoded mock data | `BusinessReview` type + service + hooks |
| Review fields | name, rating, date, text only | id, tenantId, branchId, customerId, customerName, avatar, rating, title, comment, images, visitDate, visitType, createdAt, updatedAt, ownerReply, helpfulCount, verifiedVisit, status, language, pinned |
| Verified badge | None | `verifiedVisit` field + `BadgeCheck` icon |
| Owner replies | None | `OwnerReply` sub-object + admin reply UI |
| Review moderation | None | `status` field: published/pending/hidden/spam/deleted/rejected |
| Rating distribution | None | `RatingBreakdownData` with per-star breakdown + percentage bars |
| Branch scoping | None | `branchId` field + branch-scoped queries |
| Review filtering | None | sort, verified, withPhotos, branchId, language, rating |
| Helpful votes | None | `helpfulCount` + markHelpful endpoint |
| Admin UI | None | `/console/reviews` with tabs: Published/Pending/Hidden/Spam/Analytics |
| SEO | None | `AggregateRating` JSON-LD on tenant + branch pages |
| Analytics | None | avg rating, trend, reply rate, avg reply time, top keywords, monthly trend |
