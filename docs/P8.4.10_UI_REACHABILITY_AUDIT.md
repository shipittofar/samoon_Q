## 12. Auto Fixes Applied

### Fix 1: `/console/branches/new` — Missing Page

**Problem**: The branches page rendered an "Add Branch" button (wrapped in `PermissionGuard permission="branches.manage"`) that linked to `/console/branches/new`. No page.tsx existed at that path. The Next.js dynamic route `/console/branches/[id]` was catching the request with `id="new"`, rendering the branch detail page for a non-existent branch.

**Fix**: Created `/src/app/console/branches/new/page.tsx` — a standard add-branch form with:
- Name, slug (auto-generated from name), type (physical/mobile) fields
- Location: address, city, country, postal code
- Contact: phone_number, email (optional)
- `useCreateBranch(tenantId)` hook for submission
- `PermissionGuard permission="branches.manage"` with `AccessDenied` fallback
- `ErrorBoundary` wrapper
- Cancel → back to /console/branches
- Submit → toast + router.push('/console/branches') on success

**Scope**: Minimal navigation fix only. No business logic invented, no RBAC changed, no architecture modified.
