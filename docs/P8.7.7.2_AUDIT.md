## 4. `public-url.ts`

**File:** `src/utils/public-url.ts`

```typescript
const HREF_TO_MODULE: Record<string, string> = {
  '/':            '',   // ← needs to produce /{tenantSlug} not /{tenantSlug}/{branchSlug}
  '/restaurant':  '',   // ← same
  '/menu':        'menu',
  '/reservation': 'reservation',
  '/promotions':  'promotions',
  '/events':      'events',
  '/loyalty':     'loyalty',
  '/checkout':    'checkout',
  '/reviews':     'reviews',
}

export function buildPublicUrl({ tenantSlug, branchSlug, module: mod = '' }): string {
  if (!tenantSlug || !branchSlug) {
    return mod ? `/${mod}` : '/'
  }
  const base = `/${tenantSlug}/${branchSlug}`
  return mod ? `${base}/${mod}` : base
}
```

**Required change:** `hrefToPublicUrl` for `/` and `/restaurant` must return `/${tenantSlug}` (no branchSlug). The `buildPublicUrl` function also needs to handle the case where `branchSlug` is absent but `tenantSlug` is present.

**No existing tests cover `hrefToPublicUrl` or `buildPublicUrl`** — safe to modify.
