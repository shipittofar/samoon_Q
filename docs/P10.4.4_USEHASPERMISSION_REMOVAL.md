# P10.4.4 — Remove Legacy `useHasPermission()`

Removes the second legacy RBAC API proven safe to delete by
`docs/P10.4.2_REMOVAL_PROOF.md`: `useHasPermission()`. Scope was limited
exactly to this hook, its now-unused imports, and the two tests that
asserted only its existence.

## Removed API

**`useHasPermission(permission: LegacyPermission): boolean`**
(`src/hooks/index.ts`) — the complete implementation, its section
comment (`// ── RBAC Hook — P1B.1 ──...`), and its JSDoc block. It had
zero application/UI callers (confirmed in P10.4.1 and re-confirmed in
P10.4.2); its only references were two test-only existence checks.

## Files changed

| File | Change |
|---|---|
| `src/hooks/index.ts` | Deleted the `useHasPermission()` function, its doc comment, and its section header comment. Removed the now-unused `LegacyPermission` type import (its only use in this file was `useHasPermission`'s parameter type). |
| `src/test/phase1b.test.ts` | Removed `useHasPermission` from the `@/hooks` import. Removed the `'useHasPermission is a function'` assertion. Renamed the enclosing `describe` block from `'hook contract — useHasPermission and useFeatureFlag are exported functions'` to `'hook contract — useFeatureFlag is an exported function'` and kept the `'useFeatureFlag is a function'` test unchanged. |
| `src/test/phase4-ops-advanced.test.ts` | Removed the `'useHasPermission still exported from hooks/index.ts'` source-text assertion. Kept the sibling `'rbac.service still exports hasPermission'` test — a different symbol (`rbacService.hasPermission()`, explicitly forbidden from this phase) — unmodified in the same `describe` block. |

Diff stat: 3 files changed, 2 insertions(+), 25 deletions(-).
